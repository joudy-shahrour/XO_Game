# Tic-Tac-Toe Game (Python) 
A console-based implementation of the classic Tic-Tac-Toe game built with Python. This project was developed as a foundational exercise to practice core programming concepts, control flow, loops, and robust exception handling.
## Features
Two-Player Mode: Play locally with a friend taking turns (Player X and Player O).
Input Validation: Handles invalid inputs gracefully (e.g., entering letters instead of numbers, or choosing an already occupied spot) using try-except blocks without crashing the game.
Win/Draw Detection: Automatically checks rows, columns, and diagonals to determine the winner or declare a draw.
Clean Code Structure: Utilizes lists, functions, and proper scope management.
